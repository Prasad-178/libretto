# M3 evidence export and inspection

**Goal:** Save reproducible offline test evidence, redact designated values, and inspect/replay the saved event sequence in Studio without starting execution.

**Spec:** ROADMAP.md M3; continuation explicitly requested by owner. Native implementation on main with test-first changes and regular commits.

## Contract

- `libretto test <path> --output evidence.json` writes a versioned `libretto.scenario-evidence` bundle. JSON stdout remains compatible.
- Every run includes workflow SHA-256/schema/ID, package version, source commit/dirty status when available, model/speech configuration, scripted test mode, normalized request references and projected semantic events. No raw YAML, prompts, generated text, transcripts, provider credentials, tool result data or raw timestamps.
- Scenario `sensitive_fields` names workflow field IDs. Redact values everywhere they can occur in report strings, field values and mapped tool arguments. Suppress argument fingerprints for affected calls. Checks still evaluate original values. Redaction is conservative and not a guarantee that arbitrary application data is anonymous.
- Studio opens only bounded, validated version-1 bundles, with React text rendering and no remote resources. Import/replay is independent of SessionClient. Navigation back to YAML requires an exact source hash match.
- Playback controls walk saved event sequence only. No audio, providers, tool imports, API writes or test startup.
